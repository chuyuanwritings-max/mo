# 墨

秦陵墨家工匠的肉鸽原型（4.1）。

**在线玩：** https://chuyuanwritings-max.github.io/mo/

始皇下葬那天，修陵的墨家工匠被封在墓里。只管走位，机关自动出手。

- **八卦机关**：八件基础机关就是八卦，按《说卦传》长在身上（乾首、坤腹、震足、巽股、坎耳、离目、艮手、兑口）。两件升满，开宝匣时一上一下合成一卦：上卦管怎么出手，下卦管打中以后怎样，一共 64 卦；机关满级加配对被动出纯卦
- **长按看演示**：任何图标长按（电脑上鼠标停住），弹一张墨线小图，不用字演出这件东西怎么出手、什么节拍
- **兵马俑坑**（默认）：每分钟第 40 秒涌一大波，两个 Boss 之间有铜车马、巨俑、弩阵、水银潮，杀招先画红再出手；一张无限大的地，打满 30 分钟，每分钟换一批怪，10/15/20/25 分钟 Boss 掉宝匣，30 分钟祖龙醒来
- **始皇陵 · 五层**：原来的五层墓道 + 祖龙
- **局外**：金死了不丢，机关坊买 12 项加成，19 条解锁，三个角色（墨非、小夕、阿铸）
- **电脑**：WASD / 方向键走位，Esc 暂停，1 / 2 / 3 / 4 选卡
- **手机**：按住屏幕任意处拖动走位
