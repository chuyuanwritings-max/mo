# 墨

秦陵墨家工匠的肉鸽原型（2.7）。

**在线玩：** https://chuyuanwritings-max.github.io/mo/

始皇下葬那天，修陵的墨家工匠被封在墓里。只管走位，机关自动出手。

- **兵马俑坑**（默认）：一张无限大的地，打满 30 分钟，每分钟换一批怪，10/15/20/25 分钟 Boss 掉宝匣，30 分钟祖龙醒来
- **始皇陵 · 五层**：原来的五层墓道 + 祖龙
- **局外**：金死了不丢，机关坊买 12 项加成，19 条解锁，三个角色（墨非、小夕、阿铸）
- **电脑**：WASD / 方向键走位，Esc 暂停，1 / 2 / 3 / 4 选卡
- **手机**：按住屏幕任意处拖动走位
